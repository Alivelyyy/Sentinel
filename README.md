## About

Sentinel is a Discord bot built for server security and management. It provides moderation tools, anti-raid protection, and server administration features to keep your community safe.

## Features

- **Security** — Anti-raid, anti-nuke, suspicious activity detection
- **Moderation** — Auto-mod, ban, kick, mute, warn
- **Management** — Role management, channel protection, audit logging
- **Logging** — Comprehensive event logging and reporting

## Tech Stack

- **Runtime:** Node.js
- **Library:** Discord.js
- **Database:** MongoDB
